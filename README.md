# 🛒 Shopping Cart Calculator

A simple shopping cart calculator built using **JavaScript** as a beginner project to practice fundamental programming concepts.

## 📌 About The Project

This project calculates the total price of products in a shopping cart based on their prices and quantities. It also applies a 10% discount when the subtotal is equal to or greater than 100.

The project was created as part of the **JavaScript Fundamentals Course** on HashPlus.

## ✨ Features

- Store products using Arrays and Objects.
- Calculate the subtotal using product prices and quantities.
- Apply a 10% discount when the subtotal reaches 100 or more.
- Calculate the final total after discount.
- Display results using `console.log()`.

1. Clone the repository:

```bash

```

2. Navigate to the project folder:

```bash
cd javascript-shopping-cart-calculator
```

3. Run the application:

```bash
node app.js
```
